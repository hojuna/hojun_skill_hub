# MCP/도구 선택 원칙 — 기본은 설치하지 않음

이 허브에는 **자동으로 연결되는 외부 MCP 설정이 없습니다.** 공개 저장소를 clone한 것만으로 서버 연결이나 외부 전송이 발생하지 않습니다.

| 도구/방식 | 언제 쓸까? | 기본 결정 |
|---|---|---|
| 제공된 터미널·테스트·미리보기 | 대부분의 코딩 과제 | **먼저 사용** |
| Playwright CLI / MCP | 브라우저 상호작용 반복 확인이 중요하고 사용 가능·허용될 때 | **조건부**. 설치 비용/호환/설정시간 확인 |
| Context7 등 원격 문서 MCP | 공식 문법 확인이 정말 필요하고 외부 질의가 허용될 때 | **기본 비활성**. 과제 원문·코드·파일 전달 금지 |
| Git/GitHub 도구 | 허용된 공개 참고자료 가져오기, 로컬 버전 비교 | **로컬 Git 우선**, 외부 push 금지 상황에서는 push하지 않음 |
| DB 도구 | 과제에서 DB를 제공하고 기존 CLI로 부족할 때 | **조건부** |
| 웹 검색/외부 API | 과제 안내에 필요한 용도와 외부 요청 허용이 명시될 때만 | **자동 실행 금지** |

## 선택 질문

1. 기존 터미널·파일·브라우저로 같은 작업을 검증할 수 있는가? 그렇다면 MCP 생략.
2. 도구가 **과제 입력, 파일, 코드, 결과물**을 외부 서버로 보내는가? 금지된 환경이라면 사용하지 않는다.
3. 설치·연결 시간보다 예상 이득이 큰가? 단순 실무 과제에서는 대개 '아니오'다.
4. 현재 제공된 Codex 버전과 호환되는가? 허용 없이 업그레이드하지 않는다.
5. 실패하면 기본 도구만으로 대체할 수 있는가?

권장 흐름: 먼저 완성되는 풀이 → 실제 실행 검증 → 필요할 때만 도구 확장. **도구 사용량 자체가 목표가 아니다.**
