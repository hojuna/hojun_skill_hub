# Write the requested artifact from its source

1. Identify required audience, document format, sections, length, output path and evaluation criteria. Preserve the user's or assignment's terminology.
2. Read the supplied source in full enough to support the requested claim. Separate **source facts, assumptions, analysis and recommendations**.
3. Build the smallest useful outline that satisfies required sections. Prefer concrete findings and decisions to filler.
4. For each important claim, record the supporting file/section/data. If data are missing, qualify rather than invent results.
5. Write the final artifact in the required format and path (Markdown, text, HTML or another supported format). Don't invent a mandatory PDF or presentation requirement.
6. Verify all required headings, figures, calculations, citations/attribution and accessibility of final output.
7. Give a 3–5 sentence summary of purpose, main finding, what changed, and uncertainty.

Do not send user-provided files to external summarization tools or use unapproved services. When the task asks for independent research, follow its allowed sources and network rules.
